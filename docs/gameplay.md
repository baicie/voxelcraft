# VoxelCraft 游戏规则

## 世界与模式

- 每个世界由名称、Seed 和模式构成。Seed 相同且生成器版本相同时，未修改地形确定一致。
- 生存模式：20 生命、20 饥饿、10 氧气；工具会损耗，采集受工具等级限制。
- 创造模式：初始获得一套建筑方块与工具；方块破坏立即完成、放置不消耗物品；双击 Space 切换飞行。

## 生物群系与资源

| 群系 | 地表 | 特征 |
| --- | --- | --- |
| 海洋 | 沙 | 低于海平面，水与海岸 |
| 平原 | 草 | 少量橡树、草与花 |
| 森林 | 草 | 高密度橡树/白桦，出生点优先 |
| 沙漠 | 沙/砂岩 | 仙人掌 |
| 山地 | 石/草 | 海拔变化大、矿产多 |
| 雪原 | 雪 | 云杉与低温 |
| 沼泽 | 苔石/草/水 | 芦苇、低洼地形 |
| 海岸 | 沙 | 水陆过渡 |

洞穴由三维噪声和隧道层雕刻，地下有煤、铁、金、钻石与砾石。地下还有带发光方块、金矿和石砖柱的遗迹；地表有石砖废墟。矿脉与遗迹均由种子确定，在 Chunk 边界使用世界坐标生成。

## 方块与工具

已注册 40 个方块，覆盖草/土/石/沙/雪、原木与树叶、矿石、圆石、玻璃、砖、石砖、工作台、熔炉、火把、农作物与发光方块。方块定义包含实体碰撞、透明度、硬度、工具类型/等级、掉落、纹理和光照值。

- 空手可砍树和采集土/沙，但石头需要至少木镐才掉落圆石。
- 煤矿需要木镐；铁矿需要石镐；金矿/钻石需要铁镐。
- 工具按匹配类型获得速度收益；使用会减少耐久，耗尽后消失。
- 剑用于近战，基础伤害 + 工具伤害；攻击有 0.55 秒冷却和击退。

## 背包

- 9 格快捷栏 + 27 格背包。工具不可堆叠，材料/方块通常最多 64。
- 左键拿起/放下整叠，右键拿起一半或放下一件；同种物品会自动补足堆叠上限。
- Shift + 左键在快捷栏和主背包之间快速移动。
- 数字键与滚轮切换快捷栏；Q 丢弃选中堆叠的一件，并生成世界掉落物。
- 所有移动都经过容量和数量校验，材料不足不会扣除。

## 合成

配方包含仅 2×2 可用的无序配方与需要工作台的 3×3 有序配方。匹配时会自动去掉图案周围空行/空列；选择成品后才会扣除材料，材料不足/图案错误不会消耗。

| 成品 | 材料 | 工作台 |
| --- | --- | --- |
| 木板 ×4 | 任意原木 ×1 | 否 |
| 木棍 ×4 | 木板 ×2（竖排） | 否 |
| 工作台 | 木板 ×4 | 否 |
| 火把 ×4 | 煤 + 木棍 | 否 |
| 木镐 | 木板 ×3 + 木棍 ×2 | 是 |
| 石镐 | 圆石 ×3 + 木棍 ×2 | 是 |
| 铁镐 | 铁锭 ×3 + 木棍 ×2 | 是 |
| 木/石斧 | 材料 ×3 + 木棍 ×2 | 是 |
| 木/石铲 | 材料 ×1 + 木棍 ×2 | 是 |
| 木/铁剑 | 材料 ×2 + 木棍 ×1 | 是 |
| 熔炉 | 圆石 ×8 | 是 |
| 石砖 ×4 | 石头 ×4 | 是 |
| 黏土砖 ×1 | 黏土 ×4 | 是 |
| 面包 | 小麦 ×3 | 是 |

另有玻璃、铁剑等配方，共 20 条。

## 熔炉

- 右键熔炉打开界面。用当前背包物品点击输入/燃料格，点击成品格取回。
- 每份配方默认烧炼 10 秒；燃料按秒燃烧：煤 80 秒、木板/原木 15 秒、树叶 3 秒、木棍 5 秒。
- 输入：铁矿石 → 铁锭；沙 → 玻璃；生猪肉 → 熟猪肉；黏土 → 砖。
- 输出槽满时停止烧炼；破坏熔炉会把内部所有物品掉落到世界中。

## 生存

- 饥饿随时间下降；饥饿 >17 且生命未满时缓慢恢复生命，恢复消耗饥饿。
- 跌落伤害在超过 3 格后按格数扣除；浸水时氧气持续消耗，归零后周期性溺水伤害；出水后恢复。
- 食物：苹果、面包、生/熟猪肉、腐肉。右键持食物进食，恢复饥饿；饥饿满时拒绝食用。
- 生物：猪/羊被动；狼受击后反击；夜间僵尸会发现并追击玩家。生物受伤会闪红、击退，死亡掉肉/小麦/腐肉。
- 玩家死亡会清空背包并生成掉落物、显示死亡界面；重生在种子安全出生点。死亡只结算一次。

## 昼夜与环境

- 一天 600 秒；太阳位置、方向光、天空/雾颜色、星星与云亮度由世界时间真实驱动。
- 夜晚太阳光降至约 0.16，天空明显变暗；火把/熔炉/发光方块在附近贡献最多 6 个点光源。
- 水有透明表面、蓝绿色水体、水下滤镜和游泳物理；没有完整流体传播。
- 音频由 Web Audio 程序合成；首次点击后解锁，遵守浏览器自动播放策略。

## 保存

- 暂停菜单“保存并退出”会等待完整 IndexedDB 事务后才返回标题界面。
- 每 30 秒自动保存；页面关闭前发起保存。
- 世界隔离、异步保存顺序、阻塞时错误提示和版本迁移均由存储层处理。

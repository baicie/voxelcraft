## P0 audit addendum

- Storage schema: IndexedDB version 1, stores `worlds` and `chunkEdits`.
- Player state is embedded in `worlds`; V2 will split it into `players`.
- Missing: item/inventory/block entity/entity layers, stable ID persistence,
  inventory UI, crafting/furnace, V1→V2 migration, epoch/revision guard.
- The earlier chunk double-offset bug was fixed before this log and has a
  regression test in `tests/unit/chunkMesher.test.ts`.
